# Маркировка и прослеживаемость (Честный Знак, Меркурий, ЕГАИС)

## Общий контекст

Для предприятий пищевой и молочной отрасли типично одновременное
взаимодействие 1С с несколькими государственными системами
прослеживаемости продукции: "Честный Знак" (маркировка товаров кодами
Data Matrix), "Меркурий" (ветеринарная сертификация через систему
ВетИС/ФГИС "Меркурий") и, для отдельных категорий, ЕГАИС. Каждая система
интегрируется через собственный внешний сервис/коннектор, обычно по
API оператора, а не напрямую из типовой конфигурации.

## Симптом: коды маркировки не выгружаются в "Честный Знак"

Порядок диагностики:

1. Проверить статус документа отгрузки/ввода в оборот - выгрузка кодов
   обычно привязана к проведению конкретного вида документа.
2. Проверить, что сертификат электронной подписи, используемый для
   взаимодействия с системой маркировки, действителен и корректно
   выбран в настройках интеграции.
3. Проверить журнал обмена/протокол сервиса интеграции с "Честным
   Знаком" - там фиксируется точный код ошибки ответа оператора,
   который обычно однозначно указывает причину (некорректный формат
   кода, код уже выведен из оборота другим документом, истёк токен
   доступа).

## Симптом: расхождение остатков в 1С и в системе "Меркурий"

Возникает, когда партии оформляются в 1С без своевременного оформления
парных ветеринарных сопроводительных документов (ВСД) в системе
"Меркурий", либо наоборот. Требуется сверка журнала операций по
конкретной партии в обеих системах за один и тот же период - это
процедура сверки данных между системами, а не технический сбой 1С как
такового.

## Общая рекомендация по интеграциям с гос. системами

Все три системы (Честный Знак, Меркурий, ЕГАИС) требуют действующих
токенов/сертификатов доступа и часто имеют собственные регламентные
окна недоступности на стороне оператора. Если ошибка воспроизводится
у всех пользователей одновременно и совпадает по времени с очередным
изменением в личном кабинете оператора - стоит в первую очередь
проверить статус самого внешнего сервиса, прежде чем искать причину на
стороне 1С.
