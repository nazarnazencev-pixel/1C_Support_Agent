# Доступ, пароли и учётные записи

## Пользователь забыл пароль

В 1С пароль пользователя восстановить в исходном виде нельзя - он
хранится в виде хэша. Единственный штатный путь - администратор базы
сбрасывает пароль пользователю через список пользователей
(Администрирование - Настройки пользователей и прав - Пользователи) и
задаёт новый, который пользователь затем меняет самостоятельно при
первом входе, если включено требование смены пароля.

## Пользователь заблокирован после нескольких неверных попыток входа

Если в информационной базе включена парольная политика с блокировкой
после N неудачных попыток, разблокировка выполняется администратором
вручную через тот же список пользователей, либо блокировка снимается
автоматически по истечении заданного интервала времени - конкретное
поведение зависит от настроенной политики паролей в данной базе.

## Новому сотруднику нужен доступ к 1С

Порядок обычно такой:

1. Создать учётную запись пользователя в списке пользователей базы.
2. Назначить нужный профиль группы доступа (роль) в соответствии с
   должностными обязанностями - лучше по аналогии с уже настроенным
   профилем коллеги на такой же должности, чем "с нуля".
3. Если используется RLS (ограничения на уровне записей) - убедиться,
   что новому пользователю сопоставлены нужные значения ограничения
   (например, организация, склад, подразделение).

Выдачу прав напрямую пользователю в обход групп доступа стоит
рассматривать как исключение, а не типовую практику - это усложняет
последующий аудит и поддержку матрицы прав.
