# 🤖 1C Support Agent

**1C Support Agent** — интеллектуальный помощник для автоматизации поддержки пользователей **1С** с использованием **GigaChat**.

Проект позволяет пользователю задать вопрос через веб-интерфейс и получить ответ от AI-агента, а также сохраняет историю обращений для дальнейшего анализа.

## ✨ Возможности

* 📚 подключение базы знаний 1С;
* 🔎 RAG по внутренней документации;
* 💬 Чат с AI-помощником
* 🤖 Интеграция с GigaChat
* 🌐 Удобный веб-интерфейс
* 🗄️ Сохранение истории обращений в SQLite
* 📊 Административная панель
* ⚡ Быстрая обработка пользовательских запросов

## 🏗️ Архитектура

```text
Пользователь
     ↓
Web-интерфейс
     ↓
FastAPI
     ↓
1C Support Agent
     ↓
GigaChat
     ↓
Ответ пользователю
     ↓
SQLite
```

## 🛠️ Технологии

* **Uvicorn**
* **React**

## 🎯 Цель проекта

Основная задача **1C Support Agent** — автоматизировать обработку типовых вопросов пользователей 1С, сократить нагрузку на специалистов поддержки и обеспечить быстрый доступ к необходимой информации.
