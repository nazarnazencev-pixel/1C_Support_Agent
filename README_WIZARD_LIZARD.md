# Wizard_Lizard

Веб-оболочка подключена к существующему SupportAgent и расширенной SQLite БД.

## Запуск в PyCharm
1. Установить зависимости: `pip install -r requirements.txt`
2. Проверить `.env` и `GIGACHAT_CREDENTIALS`.
3. Запустить `main.py`.
4. Открыть `http://127.0.0.1:8000/`.
5. Админка: `http://127.0.0.1:8000/admin`.
   Логин `admin1`, пароль `11111`.

## Ограничение времени ответа
Для обычного текстового чата отключены повторные запросы GigaChat и установлен timeout
одного сетевого вызова 3.8 секунды. Это оставляет запас до целевого лимита 5 секунд
на HTTP и операции SQLite. Фактическое время зависит от сети и доступности GigaChat;
это бюджет приложения, а не физическая гарантия внешнего сервиса.

## База данных
Используется существующий `support_agent.db` и `support_agent_db/schema.sql`.
Новые веб-обращения записываются с channel=`web`; сообщения, эскалации и статистика
остаются в общей БД.
